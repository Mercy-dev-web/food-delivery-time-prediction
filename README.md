# Food Delivery Time Prediction

## Project Overview
Analyzed food delivery data to identify factors affecting delivery time and built a predictive model to estimate delivery duration."

## Dataset
The dataset contains information about:
- Delivery person age
- Delivery ratings
- Order type
- Vehicle type
- Restaurant location
- Delivery location

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Model
Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE): 6.64 minutes
- R² Score: 0.18

- analysis.py
- Food_delivery.csv
